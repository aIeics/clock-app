# Changelog

## 1.0.0

First public release.

- Clock with an analog dial, digital time and date, 12/24-hour and seconds options
- Pop-out desktop widget: transparent time and date behind your windows, with lock, move, resize, fonts and colours
- Timer with hour/minute/second wheels
- Reminders with notes and daily or weekly repeats, saved to disk; missed reminders show on the next start
- Calendar week strip and day view tied to the same reminders
- Close to the system tray; Restore, Start with Windows and Quit in the tray menu
- Start with Windows, starting hidden in the tray
- Single instance: opening Clock again shows the running one
- Per-user installer (no admin rights); no VC++ runtime needed
